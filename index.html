3D Maze Screensaver: Agentic Coding with Google Antigravity

This project is a technical demo of agentic coding. I recreated the classic Windows 3D Maze screensaver with modern web standards (WebGL & Three.js) by directing an AI agent in Google Antigravity, powered by Gemini 3 Pro, using a technology I had never worked with before.

How it was built

I wrote the specification (maze generation, textures and the bot's navigation logic) and the agent implemented it. Then I reviewed the code and the result, and fixed by hand what the agent didn't get right:

  • The collision distance with the stones that flip the camera.
  • The viewing height of the rat.
  • The bot not following its navigation rule (right-hand rule, switching to the left-hand rule after each gravity flip) when a new maze started.

The whole project took about 15 hours.

Demo Features

  • Procedural generation: A new maze on every refresh.
  • Performance: Optimized WebGL rendering running smoothly in the browser.
  • Accuracy: Faithful reproduction of the original OpenGL "glitches" and camera movements.

Controls

The demo is self-running to demonstrate the autonomous navigation logic:

  • Click: Toggle ambient sound.
  • Double Click: Fullscreen mode.
